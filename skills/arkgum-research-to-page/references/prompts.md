# Prompt templates

Replace bracketed variables with run values. Keep explicit placeholders only for business inputs the user did not provide.

## Grounded research report

```text
Тема: [ТЕМА]
Аудитория: [АУДИТОРИЯ]
Рынок/регион: [РЕГИОН]
Цель будущей страницы: [ЦЕЛЬ]
Текущая дата: [ДАТА]

Используя только выбранные источники этого notebook, подготовь подробный
исследовательский отчёт на русском языке.

Включи:
1. определения и границы темы;
2. основные подтверждённые идеи;
3. актуальные изменения и тенденции;
4. вопросы, боли, возражения и задачи аудитории;
5. существующие решения и альтернативы;
6. реальные примеры и результаты;
7. противоречия между источниками;
8. пробелы в данных и вопросы без надёжного ответа;
9. последствия для будущей страницы.

Для каждого существенного утверждения укажи источник или цитату. Чётко
разделяй факты, выводы и гипотезы. Не добавляй сведения из общих знаний и не
придумывай числа, спрос, рейтинги, отзывы или преимущества продукта.
```

## Opportunity matrix

```text
Проанализируй все выбранные источники и grounded-отчёт по теме [ТЕМА].

Найди возможности для страницы или контента, которые одновременно:
- отвечают на подтверждённый вопрос или боль аудитории;
- раскрыты существующими материалами неполно, неясно или противоречиво;
- соответствуют цели [ЦЕЛЬ] и офферу [ОФФЕР];
- могут быть реализованы без неподтверждённых обещаний.

Для каждой возможности укажи:
1. формулировку вопроса или проблемы;
2. аудиторию и поисковое/решенческое намерение;
3. доказательства и ссылки на источники;
4. существующее покрытие;
5. конкретный пробел;
6. рекомендуемый page angle;
7. подходящий оффер и CTA, либо явный placeholder;
8. риски и недостающие данные;
9. оценки 1–5 по силе доказательств, полезности, дифференциации и fit;
10. итоговый приоритет и объяснение.

Не выдавай предположения о search volume, keyword difficulty или позиции в
Google за измеренные факты. Если SEO-метрик нет, напиши «нет данных».
Заверши одной рекомендованной возможностью и объясни, почему она сильнее
остальных.
```

## Evidence-led page brief

```text
На основе только источников этого notebook и выбранной возможности подготовь
подробный brief для страницы.

Входные данные:
- тема: [ТЕМА];
- аудитория: [АУДИТОРИЯ];
- выбранная возможность: [ВОЗМОЖНОСТЬ];
- оффер: [ОФФЕР];
- цель: [ЦЕЛЬ];
- CTA: [CTA];
- builder: [BUILDER].

Определи:
1. job-to-be-done и состояние аудитории до/после;
2. ценностное предложение без преувеличений;
3. ключевое обещание и допустимые доказательства;
4. последовательность секций и задачу каждой секции;
5. черновые заголовки, основной текст и CTA;
6. где именно показывать источники, доказательства и ограничения;
7. визуальную метафору, направление и компоненты;
8. мобильную структуру;
9. базовое техническое SEO;
10. доступность, производительность, аналитику и критерии готовности.

Не придумывай отзывы, клиентов, цены, результаты, функции или статистику.
Непредоставленные бизнес-данные оставляй явными placeholders.
```

## Final builder prompt

```text
Используя утверждённый page brief и только подтверждённые факты из этого
notebook, напиши законченный промпт для [BUILDER], который должен создать
адаптивную страницу.

Промпт обязан содержать:
- цель, аудиторию, оффер, CTA и ограничения;
- полную информационную архитектуру;
- готовый черновой copy для каждой секции;
- связь каждого factual claim с допустимым доказательством;
- визуальное направление, layout и поведение компонентов;
- mobile-first и responsive требования;
- semantic HTML, accessibility и performance требования;
- title, meta description, heading hierarchy, canonical и schema.org только
  там, где это уместно;
- analytics events и acceptance criteria;
- запрет на выдуманные цифры, отзывы, логотипы клиентов, награды, рейтинги,
  цитаты и гарантии позиции в поиске;
- явные placeholders для отсутствующих бизнес-данных.

Не проси builder проводить новое исследование и не разрешай ему менять
подтверждённые факты. Верни только финальный builder prompt без вступления,
объяснений и послесловия.
```

## QA audit

```text
Сопоставь page brief и builder prompt с source manifest и grounded-отчётом.

Найди:
- утверждения без источника;
- цифры или обещания, которых нет в источниках;
- потерянные противоречия и ограничения;
- подмену неизвестных SEO-метрик выдуманными оценками;
- неуказанные placeholders;
- несогласованность аудитории, оффера, CTA и структуры;
- недостающие mobile, accessibility, performance, analytics или acceptance
  criteria.

Верни таблицу: проверка, PASS/FAIL, доказательство, необходимое исправление.
После таблицы перечисли только блокирующие проблемы.
```
