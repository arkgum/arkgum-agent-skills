# Code of conduct

## Our standard

We want this project to be a useful, respectful place for people building with AI agents. Contributors and maintainers are expected to:

- discuss ideas and failures without personal attacks;
- give reproducible, evidence-based feedback;
- respect privacy, authorship, and third-party licenses;
- avoid harassment, discrimination, spam, and deceptive promotion;
- disclose conflicts of interest when recommending paid tools or services.

## Unacceptable behavior

Unacceptable behavior includes harassment, threats, publishing private information, deliberate disruption, impersonation, plagiarism, and repeated promotional content unrelated to the project.

## Enforcement

Maintainers may edit or remove comments, issues, pull requests, and contributions that violate this standard, and may temporarily or permanently restrict participation.

For sensitive reports, contact the maintainer privately through the contact options on the [`arkgum`](https://github.com/arkgum) GitHub profile. Security vulnerabilities should use the private process in [SECURITY.md](SECURITY.md).
